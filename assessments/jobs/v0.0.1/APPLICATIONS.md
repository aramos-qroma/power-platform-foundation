# Apps entorno Default

Entorno **Corporacion Peruana de Productos Quimicos S.A. (default)** — el más cargado del tenant: **43 apps + 164 flows + 22 solutions, SIN security group** (abierto a todo el tenant). Es shadow-IT histórico de citizen devs.

**Nota sobre "actividad":** vía admin API solo hay señales de *mantenimiento* (última edición/publicación) y si la app está *compartida*, no de *uso runtime* (nº de aperturas/usuarios activos — requiere la analytics API, no disponible por GET simple). Por eso "actividad" = proxy: compartida + recencia de edición. Una app sin editar desde 2022 puede seguir usándose a diario; las **compartidas** son las candidatas más probables a uso real.

**Resumen:** 43 apps, **18 dueños distintos**. Ninguna editada después de 2024 (todo legacy). **12 compartidas** (candidatas a uso real → preservar/investigar); **31 sin compartir** (probable abandono). Por propósito: **15 prueba/demo/experimento** (candidatas a borrar), **28 de negocio**. Categoría dominante: **Auditoría/Calidad (12)**.
